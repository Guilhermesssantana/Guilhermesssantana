## Pac-Man CSS Banner

Use este banner como inspiração ou adicione o código diretamente em uma página HTML.

```html
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Pac-Man CSS Banner</title>
  <link rel="stylesheet" href="pacman-banner.css">
</head>
<body>
  <div class="banner">
    <!-- Conteúdo do labirinto Pac-Man -->
  </div>
</body>
</html>
```

> O arquivo <code>pacman-banner.html</code> contém o labirinto animado completo em CSS.
